# 📊 Pipeline de Procesamiento de Datos de Meetup

**Proyecto para identificar grupos activos y eventos populares (2010-2017)**

## 📌 Descripción
Procesamiento de datos históricos de Meetup para:
- Identificar **grupos activos** (basado en membresía y actividad)
- Clasificar **eventos populares** (por asistencia, duración y ubicación)
